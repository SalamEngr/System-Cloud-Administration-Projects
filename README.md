# System-Administration-Projects
A hands-on lab project simulating an enterprise IT environment. The current build focuses on core on-premises infrastructure using Windows Server and Active Directory. It is being actively extended into a hybrid environment integrating Microsoft Azure and Entra ID.
Goal: Demonstrate practical, job-ready Systems/Cloud Administration skills — identity management, network services, security hardening, and (in progress) hybrid cloud integration — in an environment modeled after real enterprise setups.
Status: 🚧 In Progress — on-prem foundation complete, Azure hybrid extension underway.
